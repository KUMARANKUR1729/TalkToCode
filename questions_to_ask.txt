# Things worth watching for
#
# * PaymentGateway.charge has two overloads. The 2-arg one calls the 3-arg one,
#   so the call graph must show charge/2 -> charge/3 and never charge/2 -> itself.
# * `status` exists on OrderRepository and PaymentGateway (Java and Python), and
#   `formatError` exists in both useCart.js and useCheckout.js. Asking about one
#   must never answer about the other.
# * Evaluator.score calls self._model.score(...). Both classes define `score`;
#   the edge must point at ReturnRiskModel, not back at Evaluator.
# * In useCart, setItems/setTotal/setError are labelled `local`, not `external`:
#   they are bound in an enclosing scope, not imported.
# * App renders CartView renders CheckoutButton, via JSX `renders` edges.
# * The "must refuse" questions are the not-found guarantee. If any of them
#   produces a confident answer, something has regressed.
